# SNAPS-OS Scripts and Tools

Central directory for all SNAPS-OS utility scripts, tools, configurations, and
daemons. Copied to `~/.config/snapsos/` during installation.

## Components

| Component | Path | Description |
|-----------|------|-------------|
| Glyphs | `glyphs/` | Pen/stylus gesture input system |
| Vox | `vox/` | Voice-to-commands (offline STT) |
| Wayshell | `wayshell/` | Event manager daemon (layout, focus, zone) |
| Monocle | `monocle/` | Per-monitor window switcher (Waybar) |
| Fastfetch | `fastfetch/` | System info wrapper with ASCII art |
| Screenshots | `screenshots/` | Fullscreen, region, and editor screenshot scripts |
| Wallpapers | `wallpapers/` | Wallpaper group switcher |
| Help | `help/` | Built-in help system with topic browser |
| TUIs | `tuis/` | fzf-based terminal UI tools |
| Config Overview | `config-overview/` | Config file browser and checker |
| Tips | `tips/` | Random tip display system |
| Misc | `misc/` | Layout button, window marker, color display |
