# Terminal UIs

FZF-based terminal user interface scripts for common tasks.

## Tools

| Script | Alias | Purpose |
|--------|-------|---------|
| `pkg-install.sh` | `pacgui` | Pacman package browser with multi-select |
| `aur-install.sh` | `aurgui` | AUR package browser with multi-select |
| `project-select.sh` | `git-projects` | Browse git repos in projects directory |
| `layout-switch.sh` | — | Switch mangoWM layouts |
| `bar-presets.sh` | — | Toggle bar/dock presets |
| `documentation.sh` | `documentation` | Documentation links and reference sheets |

## Shared dependencies

`fzf`, `bat`, `eza`, `micro`, `yay`, `pacman`, `dms`
